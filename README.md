# Country N

**Telegram-игра на C++20 о развитии и управлении вымышленным государством.**

Country N — игра, в которой игрок управляет государством, распределяет финансирование между различными сферами и наблюдает за изменением экономических и социальных показателей.

## Возможности

- **Управление государством:** отслеживание ВВП, инфляции, безработицы, поддержки правительства и бюджетных расходов.
- **Распределение финансирования:** управление финансированием промышленности, сельского хозяйства, образования, здравоохранения, обороны и администрации.
- **Помесячная симуляция:** моделирование изменений показателей государства с каждым игровым месяцем.
- **История игры:** хранение записей о прошедших месяцах и результатах симуляции.
- **Игровые события:** поддержка событий, влияющих на игровой процесс.
- **Интерфейс Telegram-бота:** навигация по игровым разделам с помощью встроенных клавиатур Telegram.
- **Автоматизированные тесты:** проверка основных сущностей, финансирования, модели государства, истории, симуляции, событий и игровой логики.

## Технологии

- C++20
- CMake 3.20+
- TgBot — библиотека для работы с Telegram Bot API
- Boost
- libcurl
